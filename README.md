# 💪 Projeto BMVC – Dicas Fitness  
✨ *Aplicação web desenvolvida em Python com o framework Bottle (BMVC)* ✨  


## 🌟 Sobre o Projeto  
O **BMVC – Dicas Fitness** é uma aplicação web criada como parte da disciplina **Orientação a Objetos (FGA/UnB)**.  
O projeto tem como objetivo demonstrar o uso do **framework Bottle** e da **arquitetura MVC (Model-View-Controller)** em Python,  
por meio de um site simples que exibe **dicas de saúde e bem-estar**.  



## ⚙️ Tecnologias Utilizadas  
🧩 **Backend:** Python 3.11 + Bottle Framework  
🎨 **Frontend:** HTML5, CSS3, JavaScript  
📁 **Arquitetura:** MVC (Model - View - Controller)
